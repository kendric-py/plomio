# js_runtime/ready — рабочий код

Всё, что нужно потоку получения антибот-сессии, чтобы работать **прямо сейчас**. Если файл отсюда
удалить или сломать — поток перестанет выдавать сессии. Отладка, тесты и справка живут в
[`../debug`](../debug/AGENTS.md) и [`../history`](../history/AGENTS.md).

- [`ozon/`](./ozon/AGENTS.md) — Ozon: `oz_flow.py` + Node-решатель + форджер отпечатка.
- [`wb/`](./wb/AGENTS.md) — Wildberries: `wb_flow.py` / `wb_flow_warm.py` + Node-решатель.

## Правила
- Это точки входа для потребителей (`scripts/*/search_stream.py` добавляют сюда `sys.path` и делают `import oz_flow` / `import wb_flow_warm`). Не переименовывать публичные функции без обновления потребителей.
- Кэши (`cache_*.js`) и артефакты прогонов создаются автоматически и лежат в `.gitignore` — руками не править.
- Не добавлять сюда одноразовые эксперименты — их место в `debug/`.
