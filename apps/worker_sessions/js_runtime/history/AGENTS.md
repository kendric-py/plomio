# js_runtime/history — историческая справка

Материалы, которые **не нужны потоку и не нужны для повседневной отладки**: итоговый отчёт исследования
и первые сырые захваты, по которым разбирался протокол. Хранятся, чтобы можно было ответить на вопрос
«откуда взялось это решение / как выглядел оригинал». Не запускать, не импортировать из `ready/` и `debug/`.

| Файл | Что это |
|---|---|
| `REPORT.md` | Итоговый отчёт исследования от 2026-10-06/07: сравнение WB и Ozon, механика, замеры, вердикты. Раздел про Ozon — **устарел** (до исправления форджа 2026-10-07); актуальное — `ready/ozon/AGENTS.md` и `ready/ozon/FINGERPRINT.md`. Пути в тексте описывают старую раскладку `research/js_runtime/` |
| [`ozon/`](./ozon/AGENTS.md) | Первые захваты Ozon из настоящего браузера |
| [`wb/`](./wb/AGENTS.md) | Снимки SDK и челленджа Wildberries |

Если материал из `history/` понадобился для работы — переносить его в `debug/` (как инструмент) или в `ready/`
(как рабочий эталон), а не ссылаться на `history/` из кода.
