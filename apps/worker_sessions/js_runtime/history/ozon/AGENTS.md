# js_runtime/history/ozon — первые захваты Ozon

Сырые материалы первого реверса отпечатка Ozon (2026-10-06, скрипт-челлендж `v47_x`), снятые из настоящего
браузера. Потоком не читаются. Актуальные эталоны — `ready/ozon/raw/real_script_v*.json` и
`ready/ozon/template_chrome154.json`; фикстура самотеста кодека — `debug/ozon/fixtures/`.

| Файл | Что это |
|---|---|
| `real_fp.json` | Расшифрованный отпечаток (`fp`) настоящего браузера, форматированный JSON (челлендж версии `47_4`, поля `challenge`, `user_agent`, `browser`, …) |
| `real_fp_full.txt` | Тот же отпечаток в одну строку (компактный JSON, ~20 КБ) |
| `real_fp_plain.txt` | Расшифрованный отпечаток в одну строку без нормализации (~28 КБ, длиннее `real_fp_full.txt`) — промежуточный результат декодера |
| `real_result_body.json` | Тело POST `/abt/result` настоящего браузера: `token` + зашифрованный `fp` (до расшифровки) |

Формат отпечатка и принцип форджа описаны в `ready/ozon/FINGERPRINT.md` — читать его, а не эти файлы.
