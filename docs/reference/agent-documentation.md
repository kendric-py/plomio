# Правила автоматического заполнения документации агентом

При разработке нового функционала или расширении существующего агент обязан **создать или дополнить**
соответствующую документацию — а не оставлять её рассинхронизированной с кодом.

Это касается:

- [`AGENTS.md`](../../AGENTS.md) (корневой) и `AGENTS.md` конкретного приложения, если меняется
  архитектура, доменные правила или состав приложений/пакетов;
- файлов в этом каталоге (`docs/reference/`) — например, если меняется поток данных, это отражается
  в [`architecture.md`](./architecture.md); если вводится новое соглашение по коду — в
  [`gold-rules.md`](./gold-rules.md) или [`anti-patterns.md`](./anti-patterns.md);
- [`README.md`](../../README.md) — если меняется состав приложений, документов или способ запуска
  проекта.
