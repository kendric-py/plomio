# Голд-рулзы

## Структура доменной области в `packages/`

Каждая доменная область в `packages/` обязана иметь строго такую структуру:

```
packages/<domain>/
├── AGENTS.md
└── src/
    └── ...
```

- **`AGENTS.md`** обязателен для каждой доменной области. В нём документируется, что делает эта
  доменная область и для чего она предназначена.
- **При любом изменении доменной области** (новая сущность, изменение поведения, новые правила) —
  `AGENTS.md` этой области обязан быть обновлён под новые изменения в том же изменении/PR, а не
  задним числом.

Пример: [`packages/user/AGENTS.md`](../../packages/user/AGENTS.md).

## Pydantic-модели

- **Любое поле pydantic-модели обязано быть описано через `Field`**, а не просто через аннотацию типа
  со значением по умолчанию напрямую.
